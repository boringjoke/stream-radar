# 直播监控平台技术设计

## 技术栈

前端： Vue3 + TypeScript

后端： Spring Boot

组件： MySQL Redis XXL-Job WebSocket

## 架构

Vue3 \| Spring Boot \| Live Monitor \| Platform Adapter \|
B站/斗鱼/虎牙/抖音

## 数据源

B站： Room/get_info + get_status_info_by_uids

斗鱼： betard JSON

虎牙： 网页JSON解析

抖音： webcast/room/web/enter

## 监控

XXL-Job定时检测。

Redis保存当前状态。

Redis Pub/Sub广播状态变化。

WebSocket推送前端。
