# 直播监控平台-数据源接口详细设计 V2.0

版本：V2.0

------------------------------------------------------------------------

# 1. 数据源设计目标

本文档定义直播监控平台四个平台的数据采集方案：

-   哔哩哔哩
-   斗鱼
-   虎牙
-   抖音

设计原则：

1.  优先使用稳定接口
2.  接口失败自动降级
3.  不直接将异常判断为未开播
4.  所有平台统一转换为内部模型

------------------------------------------------------------------------

# 2. 数据源架构

    LivePlatformAdapter

            |

            |

    Provider


    +-------------+-------------+-------------+

    |             |             |             |

    B站          斗鱼          虎牙          抖音

Adapter负责业务。

Provider负责数据请求。

Parser负责页面解析。

# 4. B站数据源设计

## 4.1 房间信息接口

用途：

直播间链接解析。

接口：

    GET

    https://api.live.bilibili.com/room/v1/Room/get_info

请求参数：

  参数      类型   说明
  --------- ------ ----------
  room_id   int    直播间ID

示例：

    https://api.live.bilibili.com/room/v1/Room/get_info?room_id=22637261

返回字段：

  字段          说明
  ------------- ---------
  uid           主播UID
  room_id       房间ID
  title         标题
  live_status   状态
  user_cover    封面

字段映射：

    uid -> platformUid

    room_id -> roomId

    live_status -> status

------------------------------------------------------------------------

## 4.2 批量状态接口

用途：

批量检测主播。

接口：

    POST

    https://api.live.bilibili.com/room/v1/Room/get_status_info_by_uids

Header：

    Content-Type: application/json

请求：

``` json
{
 "uids":[
    672328094
 ]
}
```

返回：

``` json
{
 "code":0,
 "data":{
   "672328094":{
      "room_id":22637261,
      "uid":672328094,
      "title":"xxx",
      "live_status":1,
      "online":1000
   }
 }
}
```

状态：

    0 未开播

    1 直播中

    2 轮播

------------------------------------------------------------------------

    GET

    https://www.douyu.com/betard/{room_id}

示例：

    https://www.douyu.com/betard/123456

返回：

``` json
{
 "room":{
    "nickname":"xxx",
    "room_name":"xxx",
    "show_status":1,
    "room_pic":"xxx"
 }
}
```

字段：

  字段          说明
  ------------- ------
  nickname      主播
  room_name     标题
  show_status   状态
  room_pic      封面

状态：

    show_status=1

    LIVE


    show_status=0

    OFFLINE

# 7. 抖音数据源设计

## 7.1 主数据源

接口：

    GET

    https://live.douyin.com/webcast/room/web/enter/

参数：

  参数      说明
  --------- ------------
  web_rid   直播间标识

示例：

    https://live.douyin.com/webcast/room/web/enter/?web_rid=123456789

Header：

    User-Agent:
    Mozilla/5.0


    Referer:
    https://live.douyin.com/

------------------------------------------------------------------------

## 7.2 返回字段

主要：

    room_status

    owner

    title

    cover

映射：

    owner.nickname

    -> anchorName


    room_status

    -> status

------------------------------------------------------------------------

## 7.3 备用数据源

地址：

    https://live.douyin.com/{web_rid}

解析：

    window.__INITIAL_STATE__

    roomStore.roomInfo
